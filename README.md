# ft-product-hub

Modern AI Product Platform — built by Product Owners, for Product Management.

---

## Vision

A unified, AI-augmented workspace that helps Product Managers think faster, communicate clearer, and ship the right things — from discovery through delivery.

## Core Modules

- **Discovery** — AI-assisted research synthesis and insight extraction
- **Ideation** — Opportunity scoring and idea backlog
- **Roadmap** — Visual roadmap builder with AI-assisted prioritisation
- **Stakeholder Comms** — Auto-drafted release notes, status updates, PRDs
- **Metrics** — OKR/KPI goal-setting and outcome tracking
- **AI Assistant** — Cross-module conversational agent with full product context
