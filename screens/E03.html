Product Hub v2.4.0 — April 2026

rocket

New Features

  • Bento Grid Dashboard Layout

    Introduced a modular, high-density dashboard system that allows users to customize their view with drag-and-drop tiles for specific metrics.

    PRD-042

  • Multi-Currency Transaction Support

    Support for 42 global currencies including automatic daily exchange rate syncing for accurate cross-border reporting.

    PRD-055

  • Advanced Permission Matrix

    A completely redesigned access control layer for granular permissioning at the folder and project level.

    PRD-061
build

Improvements

  • Performance boost: 40% reduction in cold-boot time for the Analytics Engine. PRD-039
  • Enhanced accessibility: High-contrast modes now fully support WCAG 2.1 Level AAA. PRD-048
  • Updated iconography: Replaced legacy SVGs with Material Symbols for better scaling. PRD-050
  • Refined search logic: Improved fuzzy matching and predictive results in the Global Search. PRD-052
bug_report

Bug Fixes

  • Resolved a race condition during concurrent user edits on the Roadmap view.
  • Fixed an issue where SVG exports would occasionally omit the legend labels.
